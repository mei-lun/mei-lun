lsof命令的使用

列出所有打开的文件

lsof

输出的字段说明：

  • COMMAND：进程的名称。
  • PID：进程 ID。
  • USER：运行进程的用户。
  • FD：文件描述符（如 cwd 表示当前工作目录，txt 表示程序代码，mem 表示内存映射文件等）。
  • TYPE：文件类型（如 REG 表示普通文件，DIR 表示目录，IPv4 表示 IPv4 套接字等）。
  • DEVICE：设备号。
  • SIZE/OFF：文件大小或偏移量。
  • NODE：文件的 inode 号。
  • NAME：文件名或路径。

实际应用

查找占用文件的进程

如果无法卸载某个文件系统或删除某个文件，可能是因为文件被某个进程占用。使用 lsof 可以找到占用文件的进程：

lsof /path/to/file

查找端口占用

lsof -i :8080

查找已删除但仍被打开的文件

lsof | grep deleted

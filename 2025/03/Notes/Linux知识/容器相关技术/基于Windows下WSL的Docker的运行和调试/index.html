基于Windows下WSL的Docker的运行和调试

前言

首先在Windows编程的时候，我们总是会需要使用到Linux环境，或者有代码需要在Linux下运行和调试，通常的解决方式是，安装虚拟机，然后在虚拟机里面安装Linux发行版系统，很早以前的方式就是把对应的代码和文件拷贝到虚拟机中，然后在虚拟机中运行。这样非常麻烦。普通的电脑虚拟机又卡又慢，真的很不方便。然后后面在VSCode上使用Remote SSH远程连接到Linux机器上，这样就可以达到在远程机器上开发的。但是这样还是需要安装虚拟机，占用机器的大量性能。虽然比前者改善，但是还是不太好用。使用WSL就可以完美解决这个问题，WSL直接在Windows上安装，还可以导入导出到其他机器。

WSL有WSL1和WSL2的区别：

微软文档，比较 WSL 1 和 WSL 2：https://learn.microsoft.com/zh-cn/windows/wsl/compare-versions

需要补充的是，WSL2不支持串口访问，如果需要支持USB设备需要通过USBIPD-WIN项目来提供USB支持。

WSL 2 是作为 hyper-v 虚拟机运行的

关于Docker的安装

微软文档：https://learn.microsoft.com/zh-cn/windows/wsl/tutorials/wsl-containers

只有WSL2拥有完整的Linux内核所以才能支持安装docker。

先决条件是系统的版本更新到最新

  1. 更新可以使用微软官方的更新工具：https://www.microsoft.com/zh-cn/software-download/windows10 此更新不会影响系统本身的内容，还可能修复操作系统中的某些bug，还原本来错误的设置。
  2. 开启Windows功能中的虚拟机平台勾选确认，也可以在管理员权限下的cmd或者PowerShell中使用命令行dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
  3. 下载WSL2的Linux内核， 在[https://learn.microsoft.com/zh-cn/windows/wsl/install-manual#step-4---download-the-linux-kernel-update-package](https://learn.microsoft.com/zh-cn/windows/wsl/install-manual#step-4---download-the-linux-kernel-update-package)页面下载Linux内核更新包，下载完成安装，或者直接在微软的应用商店中安装。
  4. 前用适用于Linux的Windows子系统功能，如果之前使用过旧的WSL那么这个功能应该开启过。或者用管理员权限打开PowerShell运行命令行dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart也可以在Windows功能中选择启用或者关闭功能中勾选对应选项。
  5. 重启系统，设置WSL2为默认版本
  1. 使用命令wsl -l -v查看是不是WSL2
  2. docker使用通常的安装方法就可以了，安装之后可能docker服务没有启动，此时不要慌，使用service docker restart把docker服务开起来，此时还是不能正常使用Docker还需要安装Docker Desktop
  3. 下载Docker Desktop：[https://docs.docker.com/docker-for-windows/wsl/#download](https://docs.docker.com/docker-for-windows/wsl/#download)
  4. 安装完成后，设置>常规中选使用基于WSL2的引擎。
  6. 然后 设置>资源>WSL集成， 从要启用Docker集成的已安装的WSL2发行版中进行选择。
  8. 这个时候开启WSL中的镜像，就可以愉快的使用Docker了

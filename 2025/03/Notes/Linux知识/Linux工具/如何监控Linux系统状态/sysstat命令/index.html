sysstat命令

sar 命令

在使用sar -u 3命令时，输出这样的信息：

字段含义：

  • CPU：CPU 核心编号。all 表示所有 CPU 的平均值。
  • %user：用户态程序占用 CPU 时间的百分比。
  • %nice：低优先级（nice）用户态程序占用 CPU 时间的百分比。
  • %system：内核态程序占用 CPU 时间的百分比。
  • %iowait：CPU 等待 I/O 操作完成的时间百分比。
  • %steal：虚拟机被其他虚拟机占用的 CPU 时间百分比。
  • %idle：CPU 空闲时间的百分比。

关键指标的含义

  • %user：用户态程序的 CPU 使用率。如果这个值很高，说明用户态程序（如应用程序）占用了大量 CPU。
  • %system：内核态程序的 CPU 使用率。如果这个值很高，说明内核态程序（如系统调用、中断处理）占用了大量 CPU。
  • %iowait：CPU 等待 I/O 操作的时间。如果这个值很高，说明系统可能存在 I/O 瓶颈。
  • %idle：CPU 空闲时间。如果这个值很低，说明 CPU 负载较高。
  • %steal：虚拟机被其他虚拟机占用的 CPU 时间。如果这个值很高，说明虚拟机资源被过度分配。

sar（System Activity Reporter）用于收集、报告和保存系统活动的信息。

常用参数：

  • -u：显示 CPU 使用情况。
    • 示例：sar -u 1 10
      • 1：每隔 1 秒收集一次数据。
      • 10：共收集 10 次。
    • 输出字段：
      • %user：用户态程序占用 CPU 时间的百分比。
      • %nice：低优先级用户态程序占用 CPU 时间的百分比。
      • %system：内核态程序占用 CPU 时间的百分比。
      • %iowait：CPU 等待 I/O 操作的时间百分比。
      • %steal：虚拟机被其他虚拟机占用的 CPU 时间百分比。
      • %idle：CPU 空闲时间的百分比。
  • -r：显示内存使用情况。
    • 示例：sar -r 1 10
    • 输出字段：
      • kbmemfree：空闲内存大小（KB）。
      • kbmemused：已用内存大小（KB）。
      • %memused：内存使用率。
  • -b：显示 I/O 和传输速率。
    • 示例：sar -b 1 10
    • 输出字段：
      • tps：每秒的传输次数。
      • rtps：每秒的读请求数。
      • wtps：每秒的写请求数。
  • -n DEV：显示网络设备的活动。
    • 示例：sar -n DEV 1 10
    • 输出字段：
      • rxkB/s：每秒接收的数据量（KB）。
      • txkB/s：每秒发送的数据量（KB）。
  • -q：显示系统负载和任务队列长度。
    • 示例：sar -q 1 10
    • 输出字段：
      • runq-sz：运行队列长度。
      • plist-sz：任务列表长度。

iostat 命令

iostat 用于监控系统输入、输出设备的负载情况。

常用参数：

  • -x：显示详细的设备 I/O 统计信息。
    • 示例：iostat -x 2 5
      • 2：每隔 2 秒显示一次数据。
      • 5：共显示 5 次。
    • 输出字段：
      • r/s：每秒的读请求数。
      • w/s：每秒的写请求数。
      • rkB/s：每秒读取的数据量（KB）。
      • wkB/s：每秒写入的数据量（KB）。
      • %util：设备的利用率。
  • -c：显示 CPU 使用情况。
    • 示例：iostat -c 2 5
    • 输出字段：
      • %user、%nice、%system、%iowait、%steal、%idle。
  • -d：显示设备 I/O 统计信息。
    • 示例：iostat -d 2 5
    • 输出字段：
      • tps：每秒的传输次数。
      • kB_read/s：每秒读取的数据量（KB）。
      • kB_wrtn/s：每秒写入的数据量（KB）。
  • -m：以 MB/s 为单位显示数据。
    • 示例：iostat -x -m 2 5

mpstat 命令

mpstat 用于报告各个处理器的活动。

常用参数：

  • -P ALL：显示所有 CPU 的详细活动信息。
    • 示例：mpstat -P ALL 2 5
      • 2：每隔 2 秒显示一次数据。
      • 5：共显示 5 次。
    • 输出字段：
      • CPU：CPU 编号（ALL 表示所有 CPU 的平均值）。
      • %usr：用户态程序占用 CPU 时间的百分比。
      • %nice：低优先级用户态程序占用 CPU 时间的百分比。
      • %sys：内核态程序占用 CPU 时间的百分比。
      • %iowait：CPU 等待 I/O 操作的时间百分比。
      • %irq：处理硬件中断的时间百分比。
      • %soft：处理软件中断的时间百分比。
      • %steal：虚拟机被其他虚拟机占用的 CPU 时间百分比。
      • %guest：运行虚拟机的时间百分比。
      • %idle：CPU 空闲时间的百分比。
  • -I SUM：显示中断统计信息。
    • 示例：mpstat -I SUM 2 5
    • 输出字段：
      • CPU：CPU 编号。
      • intr/s：每秒的中断次数。
  • -u：显示 CPU 使用情况（默认行为）。
    • 示例：mpstat -u 2 5

其他常用参数

sar

  • -A：显示所有系统活动信息。
  • -o：将输出保存到文件。
    • 示例：sar -o output.sar 1 10

iostat

  • -p：显示每个分区的 I/O 统计信息。
    • 示例：iostat -p sda 2 5

mpstat

  • -V：显示版本信息。
  • -I ALL：显示所有中断的详细信息。

总结

  • sar：用于收集和报告系统活动信息，常用参数包括 -u（CPU）、-r（内存）、-b（I/O）、-n DEV（网络）。
  • iostat：用于监控设备 I/O 负载，常用参数包括 -x（详细 I/O）、-c（CPU）、-d（设备 I/O）。
  • mpstat：用于报告 CPU 活动，常用参数包括 -P ALL（所有 CPU）、-I SUM（中断统计）。

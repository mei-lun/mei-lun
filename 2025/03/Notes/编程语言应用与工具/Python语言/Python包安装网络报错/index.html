Python包安装网络报错

更换国内源

镜像站：[https://mirrors.tuna.tsinghua.edu.cn/help/pypi/](https://mirrors.tuna.tsinghua.edu.cn/help/pypi/)

临时某个包用特定的源

设为默认

如果pip都更新不了

这个时候大多数问题都是可以解决的,但是有的时候清华源没有我们需要的包或者需要的版本,这个时候应该换成其他的源试试。

  • 阿里云 https://mirrors.aliyun.com/pypi/simple/
  • 豆瓣(douban) https://pypi.douban.com/simple/
  • 清华大学 https://pypi.tuna.tsinghua.edu.cn/simple/
  • 中国科学技术大学 https://pypi.mirrors.ustc.edu.cn/simple/

如果Github上的包安装不下来，则可以用浏览器下载下来，使用本地安装的方式安装。

当GitHub上的包使用HTTPS下载的时候经常会下载不下来，更换SSH方式就可以下载下来，所以直接进项目的页面，更换使用SSH链接clone
